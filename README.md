# The Complete Guide to Polars for Data Science

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/norochalise/noroinsight-polars-tutorial/blob/main/Complete_Guide_to_Polars.ipynb)

A complete hands-on tutorial for Polars, the high-performance DataFrame library: load, clean, transform, group, query with SQL and optimize a 1-million-row dataset in Python.

Companion notebook for the article **[The Complete Guide to Polars for Data Science](https://noroinsight.com/polars-for-data-science-complete-guide/)** on Noro Insight.

- **Tested on Polars 2.0** (updated October 2026). Every cell runs top to bottom.
- **Dataset:** [Customer Transactions & Spending (1M rows) on Kaggle](https://www.kaggle.com/datasets/mountboy/online-store-customer-transactions-1m-rows). The notebook downloads it for you with `kagglehub`, no login needed.

## Run it

Click **Open in Colab** above and choose *Runtime → Run all*, or locally:

```bash
pip install "polars>=2.0" kagglehub jupyter
jupyter notebook Complete_Guide_to_Polars.ipynb
```
